## 3. 原文未明确、由项目补充的规则

- 原文 DDL 没有外键，本项目增加 6 个外键（全部指向 patient_info），并增加字段级 CHECK 约束。
- 原文 Hive 外部表未写 LOCATION；本项目补充显式 HDFS 路径。
- 原文 Java 后端主要是 Spark 任务触发端，只有 dataclean 一个接口；本项目按验收目标扩展为 14 个只读 REST 接口，读取 MySQL ADS 结果。
- 原文前端是单页 Dashboard；本项目扩展为管理台 + 大屏 + 9 个功能页。
- 原文未给出缺失值兜底公式；本项目采用“必须有最近体检与生活习惯才评分”的口径，覆盖率 100%，并在文档中说明后续可加中立分兜底。
- 原文环境写 Python 3.10.5、Hadoop 3.3.6、Hive 3.1.5、Spark 3.3.3；实际环境为 Python 3.13 生成、Python 3.10.11 运行 PySpark、Spark 3.3.4、MySQL 8.0.42。版本差异在 docs/08 记录。
