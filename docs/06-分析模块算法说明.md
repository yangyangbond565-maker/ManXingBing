# 06 八个分析模块算法说明

## 通用输入与输出

- 输入：HDFS /warehouse/chronic_disease/ods 下 7 个 TSV（由 MySQL 经 WebHDFS 导出），字段与业务表一致。
- 计算：PySpark 3.3.4 local[4]，Spark SQL / DataFrame。
- 输出：MySQL chronic_disease.ads_*；每模块结果行数见 ads_module_run。
- 日志：logs/spark_run.log；摘要：reports/spark_run.json。
- 数据清洗与评分均不修改 MySQL 业务原表，保证原始数据可追溯。

## M1 数据清洗与预处理

业务目标：去重、处理缺失/异常，生成清洗前后报告。

过程：
1. patient_info 按 patient_id 去重，保留 create_time 最新；过滤 gender 空、age 不在 0-120。
2. health_checkup 过滤 patient_id 空、sbp 60-300、dbp 30-200、fbg 1-40、BMI 12-50、心率 30-220、sbp>dbp。
3. 生成 bp_level：正常/正常高值/1级/2级/3级高血压。
4. glucose_level：正常/空腹血糖受损/糖尿病；bmi_level：偏瘦/正常/超重/肥胖。
5. 其余表过滤空 patient_id、非法枚举、日期倒挂、金额不勾稽。

输出：清洗前后计数（patient_info 100,000→100,000；health_checkup 300,022→300,022），异常为 0；质量报告写入 reports/。

评价：本数据集是受控生成，清洗规则用于验证链路；真实数据需按同样规则处理并记录剔除原因。

## M2 患者人群画像

- 性别：GROUP BY gender，count，percentage。
- 年龄：5 段：青年<30、中青年30-44、中年45-59、中老年60-74、老年75+。
- 省份：按患者数降序。
- 年龄×性别：交叉计数，extra_value=gender。
- 输出 33 行；总患者 100,000。

## M3 慢性病类型分布

- 疾病类型：COUNT(*)、COUNT(DISTINCT patient_id)、占比（分母为有诊断记录的患者数）、重度记录数/重度率。
- 严重程度：疾病×severity 计数，疾病内占比。
- 共病：每位患者 COUNT(DISTINCT disease_type)，再按 1/2/3 种分组。
- 年度：YEAR(diagnose_date)×disease_type。
- 输出 10 + 30 + 3 行。

实测：高血压 40,912 人、糖尿病 31,890、冠心病 23,620、脑卒中 17,200、慢阻肺 15,613、慢性肾病 12,302、慢性肝病 8,894、骨质疏松 7,206、类风湿 3,762、抑郁症 3,688。共病 1/2/3 种分别 49,900 / 35,113 / 14,987 人。

## M4 风险因素关联

- 吸烟/饮酒：lifestyle 与 disease_record 按 patient_id 关联，统计因素水平×疾病患者数；exposure_rate 为该疾病患者中该因素水平的占比。
- BMI：按 bmi_level 统计体检记录数、平均收缩压、平均血糖、平均 BMI。
- 运动/饮食：按 exercise_freq / diet_pattern 统计体检均值。
- 输出 70 行。
- 解释边界：这是关联分析，不是因果推断；未控制年龄、性别、病程等混杂因素，不能据此下因果结论。

## M5 就诊行为

- 类型：门诊/急诊/住院的就诊次数、患者数、次均费用、总费用、平均报销率、平均住院天数。
- 科室：按 department 统计就诊量、患者数、费用。
- 年度：按 YEAR(visit_date) 统计。
- 报销率 = insurance_pay / cost × 100%，cost=0 时按 0 处理。
- 输出 18 行。

实测：门诊 330,211 次、住院 137,419 次、急诊 82,440 次；总费用 6,405,901,105.17 元，次均 11,645.61 元。

## M6 用药分析

- TOP20：按 drug_name 统计使用次数、患者数、次均费用、有效率。
- 类别：按 drug_type 统计。
- 有效率：is_effective='是' / 总数；仅保留使用 >=100 次的药品。
- 联合用药：每位患者 COUNT(DISTINCT drug_type)，再按种类数分组。
- 疾病 TOP3：medication_record 与 disease_record 按 patient_id 关联，ROW_NUMBER 取每疾病前 3。
- 输出 108 行 + 30 行疾病 TOP3。

## M7 疾病发展趋势预测

原文指定算法：一元线性回归（最小二乘），年度粒度，预测 2026-2029。

模型：

~~~text
y = slope × year + intercept
slope = (nΣxy - ΣxΣy) / (nΣx² - (Σx)²)
intercept = (Σy - slope×Σx) / n
R² = 1 - SS_res / SS_tot
~~~

训练：2018-2025 年年度确诊数。实测斜率 3902.6548，截距 -7,868,580.7262，R²=0.7361。预测：2026 38,197.8；2027 42,100.5；2028 46,003.1；2029 49,905.8。

评价与局限：
- 仅 8 个年度点，样本极少；R² 只表示历史线性拟合程度，不是临床准确率。
- 数据是模拟生成，年度权重递增，趋势方向可解释，但不代表真实流行趋势。
- 未做残差诊断、置信区间、外部验证；不能用于公共卫生决策。
- 月度趋势只做描述，不将月度线性模型冒充年度预测。

## M8 健康评分

评分维度与权重：

| 维度 | 规则 | 权重 |
|---|---|---:|
| 血压 | 正常 100；正常高值 75；1级 50；2级 30；3级 10 | 20% |
| 血糖 | 正常 100；空腹血糖受损 60；糖尿病 25 | 20% |
| BMI | 正常 100；偏瘦 70；超重 60；肥胖 30 | 15% |
| 血脂 TC | <5.2 100；<6.2 70；<7.2 40；否则 20 | 15% |
| 心率 | 60-80 100；50-100 75；否则 40 | 10% |
| 吸烟 | 从不 100；已戒 80；在吸 30 | 8% |
| 饮酒 | 从不 100；已戒 80；在饮 40 | 7% |
| 运动 | 经常 100；偶尔 70；无 40 | 5% |

公式：

~~~text
health_score = round(
  bp×0.20 + glucose×0.20 + bmi×0.15 + lipid×0.15 +
  hr×0.10 + smoking×0.08 + drinking×0.07 + exercise×0.05, 1)
~~~

分级：优秀 >=85；良好 >=70；一般 >=55；较差 >=40；危险 <40；高危 <50。

数据口径：每位患者取最近一次体检 + 唯一一条生活习惯；二者缺失则不评分（当前数据 100% 覆盖）。实测 100,000 人平均 72.8；优秀 12,005、良好 50,173、一般 32,970、较差 4,761、危险 91；高危 1,718 人（1.72%）。

重要声明：评分是教学用规则模型，权重由原文给定，未经过临床验证；不能作为诊断、处方或保险依据。
