# 02 需求规格说明书

## 1. 项目目标

建设一套可部署、可运行、可演示、可提交的社区慢性病大数据分析系统，完成从模拟数据到可视化展示的完整链路，并形成代码、SQL、测试、文档、答辩材料。

## 2. 用户与场景

- 社区慢病管理人员：查看患者画像、疾病分布、高危人群。
- 大数据实训学生：理解 MySQL → Hive/HDFS → Spark → API → Vue 的链路。
- 答辩教师：检查数据量、七表关系、八模块、算法公式、真实运行证据。
- 系统不面向真实临床诊疗，不提供处方、诊断或个体医学建议。

## 3. 功能需求

### FR-01 数据生成
- 生成 100,000 名虚构患者。
- 七张表满足一对多关系和外键一致性。
- 支持固定随机种子复现。
- 不使用真实个人信息。
- 输出 CSV 与 manifest（行数、大小、SHA-256）。

### FR-02 数据入库
- 建库、七张业务表、主外键、索引、CHECK。
- 使用 Python 批量入库，支持 LOAD DATA LOCAL INFILE 和分批 INSERT 回退。
- 导入前可重复清空，导入后核对记录数。
- 记录成功/失败数量、耗时、异常。

### FR-03 数据质量
- 检查空值、重复、孤立外键、非法日期、非法数值、金额勾稽。
- 检查 10 万患者口径。
- 生成 JSON + Markdown 报告，关键问题为 0 才 PASS。

### FR-04 数据同步
- MySQL 七表导出 TSV。
- 支持 local / hdfs / webhdfs 三种目标。
- 记录同步前后行数、目标路径、日志。
- 提供 Sqoop 脚本作为备选。

### FR-05 Hive 数仓
- ODS 七表、DWD 清洗表、ADS 结果表 DDL。
- 显式 LOCATION。
- 提供 Hive 查询示例与 HDFS 校验命令。

### FR-06 Spark 八模块
- M1 清洗：去重、异常过滤、清洗报告。
- M2 画像：性别、年龄、省份、交叉。
- M3 疾病：类型、严重度、共病、年度。
- M4 风险：吸烟、饮酒、BMI、运动、饮食。
- M5 就诊：类型、费用、医保、科室、年度。
- M6 用药：TOP、类别、有效率、联合、疾病 TOP3。
- M7 预测：年度/月度 + 线性回归 2026-2029 + R²。
- M8 评分：8 维权重、0-100、五级、高危。
- 结果写 MySQL ADS；可选写 HDFS/Parquet。

### FR-07 后端
- 14 个只读 API，统一响应结构。
- 分页、筛选、详情。
- 参数校验、异常处理、日志、CORS。
- 真实读取 MySQL ADS，不返回硬编码数据。

### FR-08 前端
- 首页、大屏、画像、疾病、风险、就诊、用药、趋势、评分、患者查询、数据质量。
- 图表来自真实 API。
- 加载、空数据、错误提示。
- 关键按钮可用（查询、筛选、分页、详情、跳转）。
- 适合本科答辩的正式界面。

### FR-09 文档与答辩
- 14 类文档、API 文档、部署手册、测试报告、验收清单。
- 答辩 PPT、逐页讲稿、5-8 分钟答辩稿、演示手册、Q&A。
- 所有图表、截图、数字与实际运行一致。

## 4. 非功能需求

| 类别 | 要求 | 实现 |
|---|---|---|
| 性能 | 10 万患者查询可接受 | 分页 + 索引；常用 API 几毫秒到 2 秒 |
| 可复现 | 固定 seed、版本记录 | seed=20261020；docs/08 |
| 安全 | 不提交密码 | .env.local + .gitignore |
| 隐私 | 不使用真实个人信息 | 程序生成虚构数据 |
| 可维护 | 分层清晰、配置外置 | controller/service/config/sql/spark |
| 可部署 | 文档化命令 | README + docs/09 |
| 诚实性 | 不伪造运行结果 | docs/15 明确 HDFS/Hive 已实机、Sqoop 仅 1000 行 staging 通过 |
| 兼容性 | MySQL 8 / JDK17+ / Node18+ | 实测 MySQL 8.0.42 / JDK21 / Node24 |

## 5. 验收标准

必须同时满足：

1. patient_info 为 100,000 行，并有 SQL 查询证据。
2. 七表主外键、索引、CHECK 存在，质量检查 PASS。
3. Spark 八模块有运行日志、结果表、行数、关键指标。
4. 后端 14 个接口 HTTP 200，返回真实数据。
5. 前端构建成功，至少 10 个页面可打开，截图真实。
6. 趋势预测算法、训练区间、预测区间、R² 可解释。
7. 健康评分公式、权重、分级、缺失值口径可解释。
8. 文档、PPT、讲稿、演示手册、压缩包齐全。
9. 不能把未运行的 HDFS/Hive 描述为成功。
10. 全新环境可按 docs/08、docs/09 重新部署。

## 6. 范围外

- 真实医院 HIS/LIS 接口对接。
- 真实患者身份、医保结算、处方审核。
- 临床诊断、药物推荐、个体化治疗。
- 生产级高可用、权限体系、等保合规。
- 实时流式数据。
