# 10 常见错误排查手册

## 1. MySQL

### Public Key Retrieval is not allowed
在 JDBC URL 加 allowPublicKeyRetrieval=true&useSSL=false。

### LOAD DATA LOCAL INFILE 被禁用
执行 SET GLOBAL local_infile=1；确认客户端 pymysql 连接参数 local_infile=True。仍失败时脚本自动回退分批 INSERT。

### 中文乱码
库/表/连接统一 utf8mb4；PowerShell 控制台乱码不代表文件乱码，用浏览器或 UTF-8 编辑器检查。

### 外键约束失败
先导入 patient_info，再导入 6 张子表；不要删除被引用患者。必要时 SET FOREIGN_KEY_CHECKS=0 仅用于受控重建。

## 2. Spark

### No module named pyspark
把 SPARK_HOME/python/lib/pyspark.zip 和 py4j-*.zip 加入 Python 3.10 的 sys.path（或 python310._pth）。

### Python 3.13 运行 PySpark 报错
Spark 3.3.4 不支持 3.13；使用 Python 3.10.11，或改用 spark-sql。

### HADOOP_HOME and hadoop.home.dir are unset
设置 HADOOP_HOME，并把 winutils.exe、hadoop.dll 放入 HADOOP_HOME/bin；加 -Djava.library.path。

### Mkdirs failed / Permission denied / NativeIO$POSIX.chmod
Windows 沙箱 ACL 限制目录创建/权限设置。本项目改为：
- 直接读单个 TSV（spark.read.csv 文件路径），不读目录；
- 结果走 JDBC 写 MySQL，不写本地 Parquet。
如果必须用 HDFS，请在 Linux VM 中运行。

### Data too long for column
检查 ADS 字段长度；本项目曾把 ads_trend.grain 从 VARCHAR(10) 改为 VARCHAR(20)，因为 year_disease 超长。

### JDBC driver not found
把 mysql-connector-j-8.0.33.jar 加入 java -cp 和 spark.driver.extraClassPath。

## 3. 后端

### 8080 被占用
netstat -ano | findstr :8080，结束对应 PID；或设置 SERVER_PORT=8081。

### 数据源连接失败
确认 MYSQL80 启动、CHRONIC_DB_PASSWORD 正确、库名 chronic_disease、URL 参数正确。

### 接口 500 Unknown column
检查 SQL 别名与 ADS 表字段；例如 ads_patient_profile 的省份是 dimension_value，不是 province。

### 跨域失败
把前端地址加入 CORS_ORIGINS，重启后端。

## 4. 前端

### npm install spawn EPERM
DSH 沙箱拦截子进程管道。使用 npm install --ignore-scripts，然后 npm run build；本机已验证。普通 Windows 可正常 npm install。

### esbuild spawn EPERM
Vite 构建需要 esbuild 子进程。本项目在沙箱中通过 preview + 已构建 dist 完成演示；若需 dev，请在非沙箱终端运行。

### 页面空白
打开浏览器 Console/Network；确认 /api 代理指向 8080；确认后端已启动；确认 dist 是最新构建。

### 图表空数据
确认对应 ADS 表有行；trend?grain=month 现在同时返回 year+month；检查 API 返回 code=0。

## 5. HDFS/Hive（目标环境）

### vmrun unable to start
DSH 沙箱阻止命名管道；在 VMware GUI 手动启动虚拟机，或在普通 PowerShell 中运行 vmrun。

### NameNode is not formatted
hdfs namenode -format；确认 dfs.namenode.name.dir、edits.dir 存在且可写。

### Hive metastore 连接失败
确认 metastore 9083、HiveServer2 10000；检查 hive-site.xml 的 MySQL metastore 配置与驱动。

### Hive 外部表无数据
确认 LOCATION 与 HDFS 实际路径一致，TSV 字段数与表一致，首行没有表头（ODS 导出无表头）。
