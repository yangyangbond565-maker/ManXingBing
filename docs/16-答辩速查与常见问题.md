# 16 答辩速查与常见问题

## 1. 一句话介绍

本项目用 Python 生成 10 万名虚构慢病患者和 206 万条业务记录，经 MySQL 业务库、ODS 导出、Spark SQL 八模块分析，把结果写入 MySQL ADS，再由 Spring Boot 提供 14 个接口，Vue 3 管理台和 ECharts 大屏展示。

## 2. 七张表怎么关联

patient_info 是主表，patient_id 被 disease_record、health_checkup、lifestyle、visit_record、medication_record、follow_up 引用；lifestyle 是一对一（唯一约束），其余是一对多；外键 ON DELETE RESTRICT 防止孤立记录。

## 3. 10 万是什么

是 patient_info 的患者人数，不是七表行数相加。七表总行数 2,065,156，单独统计。原文 generate_data.py 的 TOTAL=100000 且每位患者生成 1 条 patient_info，这是依据。

## 4. 数据怎么清洗

M1：患者按 patient_id 去重保留最新；年龄 0-120；体检 SBP/DBP/血糖/BMI/心率范围；SBP>DBP；严重度/随访枚举；用药 end>=start；随访 next>=follow；就诊金额勾稽。质量脚本另做空值/重复/孤立外键/非法日期检查，结果 0 问题。

## 5. 数据怎么同步

Python 从 MySQL 导出 TSV（无表头、\N 表示 NULL），本次用 webhdfs 模式写 HDFS；Hive 建 7 张 ODS 外部表；Spark 从 HDFS 读取，结果同时写 HDFS ADS（12 表）和 MySQL ADS。Sqoop 1.4.7 已完成 patient_info 前 1000 行 staging 导入；七表全量未执行。

## 6. Spark 做了什么

八个模块：清洗、画像、疾病分布、风险关联、就诊、用药、趋势预测、健康评分。用 Spark SQL/DataFrame 做 group by、join、窗口函数、行转列、线性回归统计；结果 15 张 ADS 表。

## 7. 预测算法是什么

原文指定一元线性回归（最小二乘），年度粒度，2018-2025 训练，2026-2029 预测。公式 y=slope×year+intercept；R²=1-SS_res/SS_tot。实测 slope=3902.6548，R²=0.7361。样本只有 8 个点，不能宣称临床准确率。

## 8. 健康评分怎么算

8 维加权：血压 20%、血糖 20%、BMI 15%、血脂 15%、心率 10%、吸烟 8%、饮酒 7%、运动 5%。每个维度按分级给 0-100 分，加权求和后保留 1 位。分级：优秀>=85、良好>=70、一般>=55、较差>=40、危险<40；高危<50。实测平均 72.8，高危 1,718 人（1.72%）。

## 9. 接口怎么设计

统一 code/message/data；14 个只读接口；分页 page/size；筛选 keyword/gender/level；详情 /api/patients/{id}；异常统一处理；CORS 允许 5173/4173；后端只读 ADS，不硬编码。

## 10. 怎么证明系统真的运行成功

- MySQL：SELECT COUNT(*) patient_info=100000。
- 质量报告：reports/data_quality_report.json PASS。
- Spark：logs/spark_run.log 退出码 0；ads_* 行数；reports/spark_run.json。
- 后端：scripts/check_api.ps1 14/14；reports/api_test_report.json。
- 前端：Vite build 成功；Playwright 11 页截图；Console 0 errors。
- 图表：analysis/output 8 张 PNG + CSV。
- 文档数字与 SQL/API 一致。

## 11. 为什么用 MySQL ADS 而不是直接查 HDFS

HDFS/Hive 已实机跑通；HDFS 存 ODS 和 12 张 ADS，Hive 建 ODS/ADS 外部表。MySQL ADS 是服务层，负责稳定分页/筛选/详情，避免每次查询启动 Spark。

## 12. 项目最大的局限

Sqoop 仅完成 1000 行 staging 验证，七表全量未执行；预测/评分不是临床模型；无登录权限；模拟数据不能代表真实流行趋势。回答时要主动说明，不要夸大。

## 13. 老师可能追问

- 为什么七张表没有医生表？原文未提供，doctor_id 只是编号，不擅自扩展口径。
- 为什么 R² 只有 0.736？年度点少且数据有波动；R² 是拟合优度，不是准确率。
- 为什么高危只有 1.72%？评分分布集中在 60-80，高危阈值 50 较低；这是模型和模拟数据共同结果。
- 为什么医保+自付=费用？visit_record 的 CHECK 约束和生成逻辑保证。
- 为什么前端包大？ECharts/Element Plus 全量引入；可改按需加载。
- 如果重做，优先做什么？先做七表 Sqoop 全量/增量同步，再做权限、分区、增量同步。
