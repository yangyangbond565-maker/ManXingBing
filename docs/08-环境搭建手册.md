## 2. 版本组合与兼容性

- Spark 3.3.4 使用 Scala 2.12、JDK 8/11 兼容；本次 PySpark 用 JDK 21 运行成功（本地模式）。
- 后端 Spring Boot 2.7.18 用 JDK 21 编译/运行，源码 release=17；若用 JDK 8 需把 Java 代码中的文本块改为字符串拼接，POM 改回 1.8。
- Python 3.13 不能直接运行 PySpark 3.3.4，项目使用独立 Python 3.10.11 嵌入版运行 PySpark；生成/图表仍用 3.13。
- MySQL 8.0.42 支持 CHECK、窗口函数、递归 CTE。
- 前端 Vite 6 + Node 24；在 DSH 沙箱中 esbuild spawn 被拦截，本项目通过 preview + 已构建 dist 完成截图；普通 Windows 环境可直接 npm run dev。

## 3. Windows 安装步骤

### 3.1 MySQL
1. 安装 MySQL 8.0，设置 root 口令。
2. 启动 MYSQL80 服务。
3. 将 D:/MYSQL/bin 加入 PATH（或使用绝对路径）。
4. 允许本地导入：

~~~sql
SET GLOBAL local_infile = 1;
SHOW VARIABLES LIKE 'local_infile';
~~~

### 3.2 JDK / Maven
1. 安装 JDK 17 或 21，JAVA_HOME 指向安装目录。
2. 安装 Maven 3.6+，mvn -version 确认 Java 版本。
3. 本项目用 workspace 内 Maven 仓库，避免写系统目录：

~~~powershell
mvn "-Dmaven.repo.local=D:\官方工作区\.tools\m2repo" -DskipTests package
~~~

### 3.3 Python
1. 安装 Anaconda 3 / Python 3.10+。
2. 安装 pymysql、pandas、matplotlib、pytest：

~~~powershell
python -m pip install pymysql pandas matplotlib pytest
~~~

3. 项目已将 pymysql 放入 python/vendor，可离线导入。
4. PySpark 建议使用 Python 3.10.x；本项目使用 python-3.10.11-embed-amd64。

### 3.4 Spark / Hadoop
1. 下载 spark-3.3.4-bin-hadoop3.tgz、hadoop-3.3.6.tar.gz。
2. 解压到无空格目录（路径含中文时需确认 Java 子进程可读）。
3. 将 winutils.exe、hadoop.dll 放入 hadoop-3.3.6/bin。
4. 设置 HADOOP_HOME、SPARK_HOME、PYTHON310、MYSQL_JDBC_JAR。
5. 确认：

~~~powershell
java -version
& "$env:SPARK_HOME\bin\spark-submit.cmd" --version
~~~

若 spark-submit.cmd 因中文路径/沙箱报错，可直接用 java -cp "$SPARK_HOME\jars\*" org.apache.spark.deploy.SparkSubmit 运行，scripts/run_spark.ps1 已采用该方式。

### 3.5 Node / Vue
~~~powershell
cd frontend
npm install --ignore-scripts --cache ..\.npm-cache
npm run build
npm run preview
~~~

## 4. Linux/VMware 目标环境

虚拟机 D:/BigDataLab/Hadoop-CentOS7，配置 4 vCPU/8 GB，CentOS 7，Hadoop 3.3.6/Hive 3.1.3/Spark 3.3.4 位于 /opt。

本次实际状态：

- 用户通过 VMware GUI 手动启动，IP 192.168.20.135，主机名 hadoop。
- SSH 密钥 D:/BigDataLab/ssh/hadoop_vm_rsa 可直接 root 登录，不需要口令。
- jps 可见 NameNode、DataNode、SecondaryNameNode、ResourceManager、NodeManager、JobHistoryServer，以及 Hive Metastore/HiveServer2 的 RunJar。
- 端口：9000、9870、9083、10000、8088、22 均实际监听。
- HDFS 容量 47.76 GB，可用 42.31 GB。

启动/检查命令：

~~~bash
jps -l
hdfs dfsadmin -report
hdfs dfs -ls /
hive -e "SHOW DATABASES;"
ss -lntp | egrep ':(9000|9870|9083|10000|8088)\b'
~~~

说明：DSH 沙箱仍不能直接 vmrun 启动 VM，因此由用户在 VMware GUI 手动启动；启动后 SSH 验证成功。
