## 2. 首次部署顺序

1. 启动 MySQL80。
2. 建表：python -m chronic_disease.load_mysql --init。
3. 生成：python -m chronic_disease.generate --patients 100000 --seed 20261020。
4. 入库：python -m chronic_disease.load_mysql --truncate。
5. 质量：python -m chronic_disease.quality_check。
6. 导出 ODS 到 HDFS：python -m chronic_disease.sync_mysql_to_hive --mode webhdfs。
7. 在 VM 上执行 sql/hive/01_ods.sql 建 Hive ODS 表。
8. 设置 CHRONIC_ODS_DIR/CHRONIC_ADS_HDFS，运行 scripts/run_spark.ps1。
9. 在 VM 上执行 sql/hive/03_ads.sql 建 Hive ADS 表。
10. 写元数据：python -m chronic_disease.load_metadata。
11. 构建后端：mvn -DskipTests package。
12. 启动后端：backend/run-backend.ps1。
13. 构建前端：npm install --ignore-scripts；npm run build。
14. 启动前端：npm run preview。
15. 打开 http://127.0.0.1:4173/#/home。

## 3. 一键流水线

~~~powershell
$env:CHRONIC_DB_PASSWORD="你的口令"
powershell -ExecutionPolicy Bypass -File scripts/run_all.ps1
~~~

scripts/run_all.ps1 不启动后端/前端，只做数据链路（生成→入库→质量→ODS→Spark→元数据）。

## 4. 启动/停止

启动后端：在 backend 下双击/运行 run-backend.ps1，看到 Started ChronicDiseaseApplication 即成功。

启动前端：在 frontend 下 npm run preview。

停止：
- 后端：Ctrl+C 或结束占用 8080 的 java 进程。
- 前端：Ctrl+C 或结束占用 4173 的 node 进程。
- MySQL：服务管理器停止 MYSQL80（不要删数据目录）。
- Spark：作业结束后进程退出；如残留，结束对应 java 进程。

## 5.1 Sqoop 独立验证（已完成，范围 1000 行）

Sqoop 1.4.7 安装在 /opt/sqoop-1.4.7，使用 MySQL Connector/J 8.0.33；不改动 Hadoop/Hive 配置。

执行方式：

- 以 root 身份运行 scripts/sqoop_verify_staging.sh；
- 仅导入 patient_info 中 patient_id <= 1000 的 1000 行；
- 目标目录 /warehouse/chronic_disease/sqoop_staging/patient_info_1000；
- 不使用 --hive-import、不使用 --hive-overwrite；
- 导入后创建 Hive 外部表 ods_sqoop_patient_info_1000。

实际结果：

- MySQL 查询 1000 行；
- HDFS 1000 行、78,592 bytes；
- Hive 外部表 1000 行，字段与样例核对一致；
- 七张表全量 Sqoop 导入没有执行。

密码文件为 /root/.sqoop_mysql_pass，权限 0600；不要把密码写入脚本或提交包。

## 6. 生产化建议

- 使用独立只读账号 chronic_app，仅授予 SELECT。
- 后端加 Spring Security + JWT，前端加登录。
- Nginx 反向代理 + HTTPS。
- Spark 改为 YARN 集群，Hive 使用 MySQL metastore。
- 结果表增加分区与保留策略。
- 备份 MySQL 与 HDFS，配置监控。

## 7. 重新部署检查

- 确认 MySQL 字符集 utf8mb4。
- 确认 local_infile=ON。
- 确认 Python 3.10 可用（PySpark）。
- 确认 MySQL Connector/J 路径。
- 确认 8080/4173 未被占用。
- 确认 HDFS /warehouse/chronic_disease/ods 下 7 个 data.tsv 存在。
- 确认 Hive chronic_disease_db 有 7 张 ODS 表。
- 确认 reports/spark_run.json 中 ods_dir 是 hdfs://...。
- 确认 HDFS /warehouse/chronic_disease/ads 有 12 个结果目录。
- 确认 Hive 有 12 张 ADS 表。
- 确认 reports/spark_run.json 生成。
- 确认 Sqoop /opt/sqoop-1.4.7/bin/sqoop 存在（可选）；
- 确认 1000 行 staging 表与 reports/sqoop_verification.json 存在。
