# 技术路线与八模块速查表

## 技术路线

~~~text
Python 生成 100,000 患者
  → MySQL 7 表（2,065,156 行）
  → Python 导出 ODS TSV
  → Spark 3.3.4 八模块
  → HDFS ADS 12 表 + MySQL ADS 15 表
  → Spring Boot 14 接口
  → Vue3 管理台 + ECharts 大屏
  → Matplotlib 8 图 + 文档/PPT
~~~

## 八模块

| 模块 | 输入 | 计算 | 输出 |
|---|---|---|---|
| M1 清洗 | 7 表 ODS | 去重、范围过滤、分级 | 清洗报告 |
| M2 画像 | patient_clean | group by 性别/年龄/省 | 33 行 |
| M3 疾病 | disease_clean | count distinct、严重度、共病 | 10+30+3 行 |
| M4 风险 | lifestyle + disease/checkup | join、占比、均值 | 70 行 |
| M5 就诊 | visit_clean | 类型/科室/年度聚合 | 18 行 |
| M6 用药 | medication_clean | TOP、有效率、联合、疾病 TOP3 | 108 + 30 行 |
| M7 趋势 | disease_clean | 最小二乘线性回归 | 188 行 |
| M8 评分 | latest checkup + lifestyle | 8 维加权 0-100 | 100,000 行 |

## 关键数字

- 患者 100,000；七表 2,065,156。
- 疾病：高血压 40,912、糖尿病 31,890、冠心病 23,620。
- 平均健康评分 72.8；高危 1,718（1.72%）。
- 预测 slope=3902.6548，R²=0.7361；2026 预测 38,197.8。
- HDFS PASS；Hive ODS 7 表/ADS 12 表；Sqoop 1000 行 staging PASS（七表全量未执行）。
- API 14/14；Python 6；JUnit 3；截图 11；Matplotlib 8。

## 七表主外键

~~~text
patient_info(patient_id PK)
  ├─ disease_record(patient_id FK)
  ├─ health_checkup(patient_id FK)
  ├─ lifestyle(patient_id FK, UNIQUE)
  ├─ visit_record(patient_id FK)
  ├─ medication_record(patient_id FK)
  └─ follow_up(patient_id FK)
~~~
